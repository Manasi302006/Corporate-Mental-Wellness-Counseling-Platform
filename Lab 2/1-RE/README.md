# Requirements Engineering (RE)

## Project
Corporate Mental Wellness & Counseling Platform

## Problem Statement
Problem Statement #14 — Healthcare & Telemedicine

## Purpose
This folder contains the functional requirements (FRs), non-functional requirements (NFRs), and Requirements Traceability Matrix (RTM) for the individual project.

## Contents
- Functional Requirements (FR-001 to FR-005)
- Non-Functional Requirements (NFR-001 and NFR-002)
- Requirements Traceability Matrix (RTM)

## Functional Scope
The platform supports employee pseudonymous identity, confidential stress assessments, therapist browsing and session scheduling, anonymized clinical progress notes, and personal wellness tracking.

## Non-Functional Scope
The platform addresses scheduling reliability and timezone accuracy, data encryption, privacy, and relevant compliance requirements.
